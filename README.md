# Suzu Admin (Android Panel)

Native Android admin app for [Suzu AI](https://suzu-ai.online) — install a fresh
VPS over SSH and manage an existing one via the `/api/admin/*` REST API on the
running server.

## What it does

1. **Setup** — collect VPS IP + root password, plus the default `domain /
   AI_API_BASE_URL / AI_API_KEY / AI_DEFAULT_MODEL` for the install. Credentials
   are stored in `EncryptedSharedPreferences` (Android Keystore-backed).
2. **Install** — SSH into the VPS (JSch), run the Suzu AI installer one-liner
   from [`hairunnizam21/script_ai_panel`](https://github.com/hairunnizam21/script_ai_panel),
   stream the log, toast on completion.
3. **Manage** — once the server is up, talk to it over HTTPS using a
   `SUZU_ADMIN_TOKEN` (generated by the installer). The app can:
   - Read / update `AI_API_BASE_URL`, `AI_API_KEY`, `AI_DEFAULT_MODEL`, domain
   - List registered users with daily-token usage + Premium status
   - Grant / extend / revoke Premium for donors
   - Manage **multiple token sets** (auto-failover when one is exhausted)
   - **Export / Import** a full user-data backup (`suzu-backup-*.zip`)

The Android app never embeds SSH credentials in the bundle; they're entered by
the operator at install time and only persisted locally on-device.

## Build

Requires JDK 17, Android SDK with `platforms;android-34` and
`build-tools;34.0.0`, and Gradle 8.7+.

```bash
# from this repo root
gradle :app:assembleRelease
# signed debug APK appears at:
#   app/build/outputs/apk/release/app-release.apk
```

The release build is debug-signed for sideloading; do **not** publish to Google
Play with this signing config.

## Project layout

```
app/
  src/main/
    AndroidManifest.xml
    java/online/suzuai/admin/
      MainActivity.kt           # Compose entry + dark theme
      data/Prefs.kt             # EncryptedSharedPreferences wrapper
      net/SshInstaller.kt       # JSch session + installer streamer
      net/AdminApi.kt           # OkHttp client for /api/admin/*
      ui/SuzuAdminApp.kt        # navigation (Setup → Install → Manage)
      ui/SetupScreen.kt         # IP / password / Suzu config form
      ui/InstallScreen.kt       # SSH installer with live log
      ui/ManageScreen.kt        # config / users / tokens / backup
    res/                        # theme, icons, strings
build.gradle.kts (root)
settings.gradle.kts
```
